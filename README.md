# QRun

Расширение для Visual Studio Code, которое компилирует и запускает C++ файл одной командой.

## Автор

- Жирнов Сергей Романович
- М3112

## Возможности

- Команда **«Запуск файла Qrun»** в палитре команд (`Ctrl+Shift+P`).
- Перед запуском автоматически сохраняет файл, поэтому всегда компилируется последняя версия.
- Компилирует файл через `g++` и запускает программу, **только если компиляция прошла без ошибок**.
- Запускает программу в отдельном терминале **QRun** и использует его повторно, а не открывает новый каждый раз.
- Переключает терминал в кодировку UTF-8, поэтому русский текст выводится без искажений.
- Если открыт не C++ файл, показывает предупреждение.

## Требования

- Visual Studio Code
- Компилятор `g++`, доступный в `PATH` (например, MSYS2 UCRT64)

## Использование

1. Откройте `.cpp` файл.
2. Нажмите `Ctrl+Shift+P` и выберите **«Запуск файла Qrun»**.
3. Программа скомпилируется и запустится в терминале QRun.

## Запуск из исходников

npm install
затем F5 в VS Code — откроется окно Extension Development Host с установленным расширением.
